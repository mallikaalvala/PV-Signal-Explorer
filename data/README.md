# Data

Do not commit identifiable or full regulatory source datasets to the repository.

Place local FAERS/AEMS files outside Git or under ignored folders such as `data/raw/`.
The Streamlit UI accepts DRUG, REAC and DEMO tables and optional OUTC, INDI, THER and RPSR tables.

`data/sample/` contains synthetic demonstration data only. It is not real patient or FDA report data.
